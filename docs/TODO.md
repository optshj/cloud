## 1. 권한 요청 타이밍 — 진입 게이트

카메라 권한은 진입 시 바로 요청되는데, 위치 권한은 셔터를 누르는 순간에야 처음 요청된다
(`CameraLive.tsx`: `getUserMedia`는 mount 시 useEffect, `getCurrentPosition`은 `handleShutter` 안).
그래서 촬영 버튼을 누르는 순간 위치 권한 팝업이 튀어나와 흐름이 끊긴다.

- **결정**: 권한이 없는 상태로 카메라 화면에 들어오면 권한 요청 화면으로 먼저 보내고,
  카메라+위치 둘 다 허용되면 자동으로 원래 촬영 플로우로 넘어온다.
- **한계**: 브라우저가 위치 권한을 "이 사이트 방문 중에만 허용"으로 처리하면 세션마다 다시 뜰 수 있다 —
  완전 제거가 아니라 "셔터 시점에 처음 뜨지 않게" 정도가 현실적 목표.
