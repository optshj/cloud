# 모달 exit 애니메이션 + 낡은 카메라 케이스 수리

## 대상

`e2e/smoke.spec.ts` — 모달 exit 애니메이션 회귀 테스트를 새로 넣고, 진입 권한 게이트가 생긴 뒤로
깨져 있던 카메라 케이스를 고쳤다.

## 커맨드

```
npx playwright test e2e/smoke.spec.ts
```

## 결과

6개 전부 통과.

- **새 케이스 "피드 상세 모달은 닫힐 때 exit 애니메이션을 재생한다"** — `animationstart`를 문서
  전체에서 모아 `modal-out`·`overlay-out`이 실제로 시작했는지 본다. `data-state="closed"` 프레임을
  잡으려 하면 exit가 120ms라 불안정해서 이벤트를 모으는 쪽으로 갔다.
- **수리한 케이스 "카메라 탭은 비로그인 상태에서도 로그인으로 막지 않는다"** — 원래는 셔터
  (`button[name="촬영"]`)가 바로 보이는지를 봤는데, `44ea260`의 진입 권한 게이트가 셔터 앞에
  한 단계를 끼우면서 **이 커밋과 무관하게 계속 실패하고 있었다**(`git stash`로 클린 트리에서도
  같은 실패 확인). 게이트의 "권한 허용하기"까지만 보고, 원래 지키려던 규칙(비로그인을 막는 건
  저장뿐이라는 것)은 로그인 안내가 **안 뜨는지**로 확인한다.

## 범위 제외

- 게이트를 지난 뒤의 촬영 화면(셔터·줌)은 `getUserMedia` 목업이 있어야 볼 수 있어서 제외했다
  → 남은 작업 목록 §2-8. Playwright 기본 크로미움엔 페이크 미디어 디바이스 플래그가 안 붙어 있다.
- 사진첩 상세 모달(`EntryDetailModal`)의 exit는 로그인이 필요해 자동화 밖이다. 피드 모달과 같은
  프리미티브·같은 패턴이라 피드 쪽 통과로 갈음했다.
- 삭제 확인창 state가 모달을 다시 열 때 접혀 있는지도 로그인이 필요해 자동화 밖이다.
