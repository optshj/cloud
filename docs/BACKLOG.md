## 1. 바로 할 수 있는 것

막힌 것 없이 지금 착수 가능한 것들. 위에서부터 값어치 순.

### 1-1. lint 부채 129건 정리 — 별도 커밋

`npm run lint`가 레포 전체에서 실패한다. 이번 작업들과 무관한 기존 부채다.

- **79건은 `npm run lint -- --fix` 한 방**으로 끝난다(대부분 prettier 줄바꿈).
- 나머지 50건은 손으로 — 대부분 `no-restricted-syntax`(함수 선언식 → 화살표 함수),
  일부 `consistent-type-imports`, `naming-convention`(불리언 변수 접두사).
- 특정 디렉터리에 몰려 있지 않다 — 레포 전체다. 스코프를 미리 좁히지 말 것.

**CI가 없어서 이게 계속 쌓인다.** 정리 커밋과 함께 pre-commit 훅이나 CI를 붙일지 판단이 필요하다
— 안 붙이면 다음 세션에 또 같은 양이 쌓인다.

### 1-2. 터치 타겟 44px 마무리 (a11y)

`EntryDetailModal`의 "삭제하기"(세로 ~20px)부터 — 셋 중 유일하게 WCAG 2.2 최소 24×24에도
미달한다. → `UI-SYSTEM.md` "남은 것"

### 1-3. `role="status"` vs `role="alert"` 기준 통일

지금 섞여 있다. 셔터가 안 먹은 이유(위치 조회 실패)는 즉시 알려야 하므로 `alert`가 맞을 수 있다.
→ `UI-SYSTEM.md` "남은 것"

## 2. 트리거가 오면 반드시 — 조건부

지금 고치면 과설계지만, 아래 조건이 오는 순간 **같이** 해야 하는 것들.
조건 없이 미리 하지 말 것.

### 2-1. `photo_path`의 user_id 노출 → **프로필·팔로우가 붙을 때**

`entry_feed`에서 `user_id` 컬럼은 뺐지만 `photo_path`가 `{user_id}/{date}.jpg`라
폴더명으로 그대로 샌다. 지금은 user_id로 사람을 특정할 수단이 없어 알려진 한계로 뒀다.
**고칠 때 네 군데가 함께 움직여야 한다** — 특히 `storage.objects` RLS가 폴더명에
쓰기 권한을 걸고 있어서 경로만 바꾸면 권한이 열린다.
→ `CONVENTIONS.md` "알려진 한계" (배경·영향 범위 전부 거기 있다)

### 2-2. `PlaceholderPhoto`의 `isLoaded` 리셋 → **서버 프리페치를 도입할 때**

지금은 목록이 빈 배열로 시작해 SSR HTML에 `<img>`가 안 실려서 안 드러난다.
서버에서 entries를 프리페치하는 순간 캐시된 이미지의 `onLoad`가 유실돼
사진이 `opacity-0`으로 영영 안 보인다. → `UI-SYSTEM.md` "남은 것"

### 2-3. 사진첩 조회를 서버 필터로 → **로더 대기가 눈에 띄게 길어지면**

`CalendarView`가 전체 기록을 받아 `isMine`으로 걸러 대부분 버린다.
지금 규모에선 훅을 피드와 공유하는 게 맞다. 옮길 땐 `entry_feed`가 뷰라
`.eq("is_mine", true)`가 PostgREST에서 그대로 먹고, 그때 클라이언트 필터 한 줄도 같이 지워진다.

### 2-4. `useCloudEntries`의 auth 변화 재조회 → **빈 사진첩 제보가 들어오면**

`is_mine`은 fetch 시점 토큰으로 서버가 계산하는데 훅에 `onAuthStateChange` 구독이 없다.
최초 요청에 토큰이 안 실리면 **에러 없이 조용히 빈 화면**이 된다(로그가 안 남아 재현이 어렵다).
코드상 깨질 확률은 낮다 — `auth/callback`이 서버에서 쿠키를 굽고 풀 리다이렉트를 한다.

## 3. 결정이 필요한 것 — 사람이 정해야 진행됨

### 3-1. 서비스명 (다른 것들을 막고 있다)

`PRODUCT.md`의 유일한 미정 사항인데, 공유 카드 워터마크가 이걸 기다리며
**플레이스홀더 문자열 그대로 나가고 있다**:

```
src/features/share-card/lib/share-card.ts:78
ctx.fillText("서비스 로고 · 나도 오늘 구름 기록하기", 32, height - 40);
```

카드 이미지 내보내기는 바이럴 도달용 기능이라, 이름이 정해질 때까지 그 목적을 못 한다.
Supabase 프로젝트명은 "뭉게뭉게"로 돼 있다 — 이걸 확정할지 따로 정할지.

### 3-2. IA 중복 — 사진첩이 같은 데이터를 두 번 보여준다

달력 그리드와 폴라로이드 리스트가 같은 달 기록을 각각 렌더한다.
화면 구조 재설계라 `PRODUCT.md` 플로우와 함께 다뤄야 한다. → `UI-SYSTEM.md` "남은 것"

### 3-3. 모달 exit 애니메이션 — 할지 말지

호출부가 `{selected && <Modal/>}`로 조건부 마운트해서 부모가 먼저 사라진다(enter만 동작).
고치려면 Dialog root를 상시 마운트하고 `open`만 토글하는 구조 변경이 필요하다 —
호출부 전체가 바뀌므로 값어치를 먼저 판단할 것. → `UI-SYSTEM.md` "남은 것"
