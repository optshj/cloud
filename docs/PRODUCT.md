# 제품 스펙 — 구름 수집 서비스

매일 하늘/구름을 즉석 촬영하면 AI가 러프한 감성 코멘트를 붙여 캘린더에 기록하는 개인 다이어리 앱. 전체공개 피드로 다른 사용자의 기록도 구경할 수 있어 동기부여를 유지한다.

아래 스펙은 그릴링(요구사항 인터뷰)으로 확정된 내용이며, 구현 시 이 문서가 제품 결정의 유일한 기준이다. 서비스명은 아직 미정이다 — → [`TODO.md`](TODO.md) §3-1.

## 디자인 스타일

**네오브루탈리즘**(굵은 검은 테두리, 하드 섀도 — 블러 없는 오프셋 그림자)으로 확정. 컬러는 원색이 아니라 **파스텔 그라데이션**(하늘색/라벤더/코랄 계열)을 쓴다 — 구조(테두리/섀도/그리드)는 브루탈리즘 원칙을 따르되 색은 서비스 감성에 맞춰 파스텔로 확정(사용자 목업 [`mockups/vertical_archive_cards_corrected.png`](mockups/vertical_archive_cards_corrected.png) 기준). 화면별 배경 톤: 카메라 하늘색, 캘린더/사진첩 라벤더, 피드 코랄/핑크.

화면별 목업: [카메라](mockups/카메라%20화면.png) · [카메라 모달](mockups/카메라%20화면%20모달.png) · [사진첩](mockups/사진첩%20화면.png) · [사진첩 모달](mockups/사진첩%20모달.png) · [피드](mockups/피드%20화면.png) · [피드 모달](mockups/피드%20모달.png)

## 핵심 루프

촬영 → AI 코멘트 → 캘린더 저장 → (선택) 공유

## 확정된 제품 스펙

| 영역      | 결정                                       | 비고                                                                                                                                                                  |
| --------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 업로드    | 하루 1장, 즉석 촬영만                      | 갤러리 업로드 금지 — 진정성이 핵심 재미 요소. 저장 전 재촬영 확인 단계 필수                                                                                           |
| AI 코멘트 | 러프한 감성 코멘트                         | 구름 여부는 검증하지 않는다(하늘 아닌 사진도 그냥 코멘트) — 검증 로직을 임의로 추가하지 않는다                                                                        |
| 캘린더    | 사진첩은 본인 기록만 열람                  | 남의 기록을 구경하는 건 피드가 맡는다 — 사진첩은 내 앨범이라 남의 사진이 섞이면 "내가 며칠 채웠나"가 안 읽힌다                                                                                                                                                      |
| 피드      | 전체공개, 좋아요만                         | 댓글 없음 — 모더레이션 부담 회피가 목적이니 임의로 추가하지 않는다                                                                                                    |
| 위치      | GPS 자동 수집 → 동 단위로 변환해 저장/표시 | 정확한 좌표를 그대로 노출하지 않는다(프라이버시)                                                                                                                      |
| 로그인    | 소셜로그인(카카오 등), 비로그인 탐색 허용  | 좋아요/업로드 시에만 로그인 요구                                                                                                                                      |
| 신고      | 신고 버튼 + 누적 시 자동 숨김              | 전체공개 서비스의 최소 안전장치 — 생략 금지. 피드의 카드 상세(스택 뷰)에 작은 아이콘으로 배치. 사진첩은 본인 기록만 보여주므로 신고가 성립하지 않아 붙이지 않는다                                                                  |
| 외부 공유 | 카드 이미지 내보내기(다운로드)             | 촬영 직후 확인 화면("기록하기"/"다시찍기"와 나란히 "다운로드" 버튼)에서 바로 카드 이미지를 받을 수 있다. 카드에 서비스 이름/링크를 최소한이라도 넣는다(바이럴 도달용) |
| 탈퇴      | 즉시 전체 삭제                             | 사진/캘린더/위치기록 포함, 유예기간 없음                                                                                                                              |
| 알림      | v1 없음                                    | 웹뷰 앱 전환 시 네이티브 푸시로 재검토                                                                                                                                |
