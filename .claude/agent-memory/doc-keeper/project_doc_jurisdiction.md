`docs/*.md` 첫 정리(2026-09-02, 커밋 `c01138f`)에서 확정한 배치. 소유권 표를 새로 만들지
않기로 했으므로(그 표 자체가 다음 드리프트 면이 된다) 여기 남긴다.

**2026-09-03 개편: 열린 항목은 전부 `docs/TODO.md` 한 곳이다.** `BACKLOG.md`는 삭제했고
(가리키기만 하는 문서가 오히려 드리프트 면을 하나 더 만들었다), 원문 문서에 흩어져 있던
"남은 것 / 미정 사항 / 알려진 한계 / 다음에 볼 것"은 **배경까지 통째로** TODO.md로 옮겼다.
원문에는 한 줄 포인터만 남아 있다.

- **미해결 항목은 배경·수치·선택지까지 전부 `TODO.md`.** 이제 "포인터만 두고 원문이 배경을
  갖는다"가 아니라 반대다 — TODO.md가 자족적이어야 한다. 원문을 열지 않아도 착수할 수 있게.
- **원문 문서는 "지금 어떻게 동작하고 왜 그렇게 정했는지"만.** 확정된 결정·현재 스키마·현재
  화면 순서. 미해결이면 원문에 쓰지 않는다.
  - `ERD.md` → 지금 올라가 있는 스키마 사실. `CONVENTIONS.md` → 그 사실에서 얻은 판단 규칙
    (예: "노출 여부는 뷰가 아니라 테이블 권한에서 확인한다").
  - `PRODUCT.md` → 확정된 제품 스펙. `UI-SYSTEM.md` → 프리미티브·상태 표현·모션 결정과 시행착오.
  - `FLOWS.md` → 화면 순서(+짧은 사유 한 줄). `test-results/*.md` → 실행 결과 기록.
- **새 TODO를 원문 문서에 적지 않는다.** `CLAUDE.md` 개요절이 이 규칙을 선언한다.
- 코드에 남기는 `ponytail:` 주석도 **천장만 적고 착수 조건은 `docs/TODO.md §n`으로 가리킨다.**

**Why:** 같은 주제가 여러 자리에 앉으면 그 자리들이 서로 반대로 서고, 다음 agent가 틀린 쪽을
근거로 판단한다. 실제로 GPS 처방이 그렇게 어긋나 있었다 — [[gps-fix-was-wrong]] 참고.

**How to apply:** 새 중복을 발견하면 위 배치를 먼저 적용한다. 위에 없는 주제만 머리말의
관할 선언으로 새로 판정하고, 겹쳐서 안 서면 사용자에게 묻는다.
