**클라이언트 조회 계층의 동작·실패 모드를 소유하는 문서가 없다.** (2026-09-02 확인, 미해결)

`TODO.md` §2-3(사진첩 조회를 서버 필터로)과 §2-4(최초 조회 토큰 누락 → 조용히 빈 사진첩)는
배경이 TODO.md 밖 어디에도 없다. 후보를 다 짚어봤지만 전부 관할 밖이었다 —
`UI-SYSTEM.md`는 프리미티브·상태 표현·모션, `FLOWS.md`는 "지금 동작하는" 화면 순서(잠재 실패
모드가 아니다), `ERD.md`는 스키마다. 그래서 이번엔 TODO.md에 남겨두고 보고에 올렸다.

**Why:** 관할이 겹칠 때가 아니라 **비었을 때**라 임의로 새 문서를 만들면 그게 다음 드리프트
면이 된다. 사용자가 정해야 할 문제다.

**How to apply:** 다음에 같은 종류(훅·캐시·재조회 같은 클라이언트 데이터 계층) 중복이 또
나오면 임의 배치하지 말고 사용자에게 이 건과 묶어서 묻는다. 사용자가 새 문서를 만들라고 하면
첫 문단 관할 선언 + 이관 포인터 규칙을 그대로 적용한다.
